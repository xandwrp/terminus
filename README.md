# Terminus Reborn

> A nextbot for Garry's Mod that stalks you from the dark, chases you down and eats you.

On the [Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=2873467078). A rebuild of the original Terminus, which started out as Gargin's "Stalking Nextbot", Gargitron.

## Spawning

NPCs > Terminus. Put it down anywhere, it shows up somewhere else when it's ready.

Needs a navmesh. If the map hasn't got one, run `nav_generate`.

## What it does

- Stalks, lurks, chases, ambushes and enrages, each on its own timer
- Hides in the dark unless it's close or in your flashlight
- Hunts players, NPCs and nextbots, VJ Base and DrGBase included
- Picks someone new each time it moves on, and turns on whoever spots it
- Flies after you if you hang out of reach too long
- Music, heartbeat and colour drain while it's after you, for spectators too

## Settings

Spawn menu > Utilities > Terminus, or the convars. Server ones start with `terminus_` and are for superadmins, client ones start with `terminus_cl_`.
